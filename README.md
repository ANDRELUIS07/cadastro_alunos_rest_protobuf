# Cadastro de Alunos — REST e Protocol Buffers

## Sobre o projeto

Projeto desenvolvido em Java com o objetivo de implementar um sistema de cadastro de alunos, explorando a comunicação via API REST e a serialização de dados utilizando Protocol Buffers (Protobuf).

## Tecnologias utilizadas

- **Java** — linguagem de programação.
- **Spring Boot** — desenvolvimento da aplicação backend e da API REST.
- **Maven** — gerenciamento de dependências e build do projeto.
- **Protocol Buffers (Protobuf)** — serialização eficiente de dados.
- **Git e GitHub** — controle de versão e hospedagem do código.

## Funcionalidades

- Cadastro de alunos.
- Exposição de endpoints REST.
- Utilização de Protocol Buffers para representação ou transmissão de dados.

> As funcionalidades descritas devem ser ajustadas conforme o que já está implementado no projeto.

## Pré-requisitos

Antes de executar o projeto, você precisa ter instalado:

- JDK compatível com a versão utilizada no projeto.
- Maven, caso não utilize o Maven Wrapper.
- Git.

## Como executar

1. Clone o repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd cadastro-alunos-rest-protobuf
   ```

3. Execute os testes:

   ```bash
   mvn test
   ```

4. Execute a aplicação:

   ```bash
   mvn spring-boot:run
   ```
